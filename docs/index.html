GET STARTED

三步接入你的 Agent

装好后对 Agent 说一句「用摸鱼绿把这篇文章排成公众号 HTML」即可。

1

一行安装（或让 Agent 自行 clone 到 skills 目录）

npx skills add https://github.com/<你的GitHub用户名>/<仓库名>

也可以手动：git clone 本仓库到 ~/.claude/skills/gzh-design（Codex / Cursor 同理，放到各自的 skills 目录）。

2

写好 Markdown，交给 Agent 并指定主题

用摸鱼绿把这篇文章排成公众号 HTML：article.md
3

打开生成的预览页，点「复制到公众号」，去编辑器粘贴

脚本会自动跑完双关卡校验（组件库源头关 + 产物合规关），直引号问题由 fix_quotes.py 安全修复，ERROR 清零才交付。

PIPELINE

工作流一览

确定性规则全部沉淀在组件库与脚本里，模型只做内容判断——换模型不走样，国内外模型都能跑出一致效果。

① 选主题按题材推荐，7 套内置 + 生成器现造
② 读组件库主题库 + 通用增量库，HTML 从库里取
③ 解析结构标题/章节/引用/代码块/表格/图片
④ 装配 HTML自动编号、关键词下划线、全角标点、签名合并
⑤ 双关卡校验component_lint + validate，ERROR 清零
⑥ 一键复制预览页复制按钮，粘贴进公众号不掉格式
