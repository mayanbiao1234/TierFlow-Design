完全不懂代码，也能用吗？＋

可以。复制上面那句话，发给支持技能安装和文件处理的智能体，并附上文章即可。安装、选择主题、排版和校验由智能体执行；你负责检查生成的内容和最终粘贴效果。

任意聊天机器人都可以吗？＋

需要能够读取仓库、处理文件并运行技能的智能体。只支持文字对话的聊天工具，可能无法直接安装技能或生成可用文件。网站本身用于介绍和预览，实际排版在你的智能体里完成。

我只有 Word 或一段文字，怎么办？＋

直接发给智能体。纯文本、Word 和 PDF 会先提取为文章结构，再进行排版；文件提取取决于你所用智能体的能力。扫描版 PDF 或复杂表格可能需要补充核对。

能指定主题，或做自己的风格吗？＋

可以。在提示词里加上「使用极简优雅白」等主题名称，或给一段风格描述、一张参考图，让智能体生成并保存新的主题组件库。

文章会上传到这个网站吗？＋

这个展示网站没有文章上传入口，也不接收你的稿件。文章由你选择的智能体处理，处理方式与数据规则以该智能体服务为准。
